# 期权课程图片资源目录

本目录存放**期权研究院 > 期权课程**分类下的所有文章图片资源。

## 📁 目录结构

```
public/img/options/course/
├── [文章slug]-cover.webp        # 文章封面图
├── [描述性名称].webp             # 文章内部配图
└── README.md                     # 本说明文件
```

## 📝 命名规范

### 1. 封面图命名
格式: `[文章slug]-cover.webp`

示例:
- `why-be-an-option-seller-cover.webp` - 为什么做期权卖方
- `options-safety-belt-cover.webp` - 期权安全带
- `monthly-cash-flow-wheel-cover.webp` - 现金流轮动策略

### 2. 内容配图命名
格式: `[描述性英文名称].webp`

示例:
- `rolling-options.webp` - 移仓修补示意图
- `wheel-strategy-diagram.webp` - 轮动策略流程图
- `option-seller-advantage.webp` - 期权卖方优势对比图

## 🎯 使用方式

在Markdown文章中引用图片:

```markdown
# 封面图
![文章封面](/img/options/course/why-be-an-option-seller-cover.webp)

# 内容配图
![移仓修补示意图](/img/options/course/rolling-options.webp)
```

## 💡 图片要求

- **格式**: 优先使用 webp 格式(体积更小,加载更快)
- **命名**: 使用小写字母+连字符(kebab-case)
- **大小**: 封面图建议宽度1200px以上,配图根据实际需要
- **压缩**: 上传前建议使用工具压缩以提升加载速度
