## 1. 定位与边界
- silentxx.com（寂静猎手·期权实战）+ wenxin.silentxx.com（问心·自留地）两个独立 Astro 项目+独立 Vercel 项目+独立私有仓库
- 边界：不含超级终端网页版（/private/x 由 silentxx-app 生成器注入）、不含 Companion 后端
- 相关技能：silentxx-website-workflows、silentxx-deploy、silentxx-sync-zh-en、silentxx-category-system

## 2. 操作文档
- 构建：停 dev 后 `pnpm build`（清 .astro+dist 缓存防隐错）；部署：`vercel --prod --yes`（webhook 假连接常复发，CLI 是唯一可靠路径）
- 双语：zh 为源，en 镜像；改完必须 `pnpm build` 验证
- 私人频道：`src/pages/private/`（密码门 PrivateLayout），cron 产物 5 个文件永不 push
- git commit 触发 lint-staged+prettier（自动展开压缩过的 x.astro）

## 3. 使用说明
- 公开：文章/教程/策略/实盘分享（trading-journal 统计卡+总账卡）
- 私人：指挥台/深度报告/笔记库/作战室（密码门）
- 问心栏目：按摩大叔/南洋往事/何处觅知音/投资×AI/瞬间

## 5. 踩坑记录
- webhook 假连接：push 成功线上无更新（Dashboard Redeploy 无效）→ 必须 CLI
- YAML frontmatter：title 冒号要引号；en 版 desc `: ` 会炸
- 生成器取 script：必须按内容定位 `function RP(` 块，不能取 scripts[0]（115 字符防闪现小块）
- patch .astro 可能引入隐形字节损坏（lint 过但 rolldown 报错）→ 整体 write_file 重写
- 递归 JSX 在 frontmatter 函数里报 `>` expected → 用 set:html 字符串拼接
- curl 测中文 URL 必须 percent-encode

## 6. 经验
- 推送前先停 dev 再 build（React island 坑）
- 改 UI 只改指定部分，先备份后校验
- CSS 作用域正则慎用 \bX，用 (^|[^\w-])
- 公开站内容分级：只真实复盘+洞察+教学；情报诊断仅 private
