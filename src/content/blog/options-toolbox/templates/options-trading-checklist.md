## 为什么需要交易检查清单？

期权交易的失败，80%源于**情绪化决策**和**流程缺失**。

### 检查清单的3大价值

1. **标准化流程**：避免遗漏关键步骤
2. **情绪隔离**：用系统替代感觉
3. **可复盘**：记录每笔交易的决策依据

## 核心检查清单模板

### 📋 开仓前检查清单（Pre-Trade Checklist）

#### ✅ 标的筛选（Underlying Selection）

- [ ] **我愿意持有这只股票吗？**（针对CSP/Wheel策略）
- [ ] **日成交量 > 100万股？**
- [ ] **期权日成交量 > 1000手？**
- [ ] **买卖价差 < 权利金的10%？**
- [ ] **财报日期确认？**（避开财报前7天）
- [ ] **重大新闻检查？**（如FDA审批、并购消息）

---

#### ✅ 策略选择（Strategy Selection）

- [ ] **策略类型确定？**
  - [ ] Cash-Secured Put (CSP)
  - [ ] Covered Call (CC)
  - [ ] Credit Spread
  - [ ] Iron Condor
  - [ ] Protective Put
  - [ ] 其他：____________

- [ ] **策略符合当前市场环境？**
  - [ ] 震荡市：卖方策略（CSP/CC/IC）
  - [ ] 趋势市：买方策略（Long Call/Put）
  - [ ] 高波动：卖出策略
  - [ ] 低波动：买入策略

---

#### ✅ 期权参数（Option Parameters）

- [ ] **到期日选择？**
  - [ ] 30-45天（推荐）
  - [ ] 7-14天（高频玩家）
  - [ ] 60-90天（保守玩家）

- [ ] **行权价选择？**
  - [ ] Delta：______（建议卖方0.2-0.3，买方0.5-0.7）
  - [ ] 支撑位/压力位确认：______

- [ ] **隐含波动率检查？**
  - [ ] IV Rank：______%（卖方建议>50%，买方建议<30%）
  - [ ] IV Percentile：______%

- [ ] **Greeks确认？**
  - [ ] Delta：______
  - [ ] Theta：______（卖方为正，买方为负）
  - [ ] Vega：______
  - [ ] Gamma：______

---

#### ✅ 收益与风险（Risk/Reward）

- [ ] **最大收益计算？**
  - 卖方：权利金 × 100 = $______
  - 买方：无限或行权价差 × 100 = $______

- [ ] **最大损失计算？**
  - 卖方：(行权价 - 权利金) × 100 = $______
  - 买方：权利金 × 100 = $______

- [ ] **盈亏比确认？**
  - 最大收益 / 最大损失 = ______ : 1
  - 卖方建议 > 1:3（33%收益率）
  - 买方建议 > 2:1

- [ ] **胜率估算？**
  - Delta即为胜率参考（Delta 0.3 = 30%被行权 = 70%胜率）

- [ ] **年化收益率计算？**（针对卖方）
  - (权利金 / 保证金) × (365 / 到期天数) = ______%

---

#### ✅ 资金管理（Position Sizing）

- [ ] **单笔仓位占比？**
  - [ ] < 5%（推荐）
  - [ ] < 10%（激进）
  - [ ] 实际金额：$______

- [ ] **账户剩余流动性？**
  - [ ] 保证金使用率 < 50%
  - [ ] 剩余现金：$______

- [ ] **止损线设定？**
  - [ ] 浮亏达权利金的200%平仓
  - [ ] 或股价跌破关键支撑位：$______

---

### 📋 持仓中检查清单（Position Monitoring）

#### ✅ 每日监控（Daily Check）

- [ ] **盈亏状态？**
  - 当前盈亏：$______ / ______%

- [ ] **是否触及止损线？**
  - [ ] 是 → 立即平仓
  - [ ] 否 → 继续持有

- [ ] **Delta变化？**（针对卖方）
  - Delta接近0.5时考虑平仓或调整

- [ ] **Theta衰减进度？**
  - 已赚取______% Theta

---

#### ✅ 异常情况（Exceptional Events）

- [ ] **标的发布重大新闻？**
  - [ ] 财报超预期 / 远低于预期
  - [ ] FDA审批结果
  - [ ] 并购消息
  - [ ] 管理层变动

  **应对：** 评估是否需要提前平仓

- [ ] **隐含波动率暴涨/暴跌？**
  - [ ] IV Rank变化 > 20%

  **应对：**
  - 卖方：IV暴跌时考虑提前平仓锁定利润
  - 买方：IV暴涨时考虑获利了结

---

### 📋 平仓前检查清单（Exit Checklist）

#### ✅ 获利平仓（Profit Taking）

- [ ] **已赚取目标利润？**
  - [ ] 卖方：权利金的50%-70%
  - [ ] 买方：本金的100%或翻倍

- [ ] **Theta衰减加速？**
  - [ ] 到期前7天，剩余权利金<25%

- [ ] **风险/收益比恶化？**
  - 剩余利润空间小，但风险依然存在

---

#### ✅ 止损平仓（Stop Loss）

- [ ] **触发止损条件？**
  - [ ] 浮亏达权利金200%
  - [ ] 股价跌破关键支撑/突破压力
  - [ ] Delta接近0.7（深度价内）

- [ ] **基本面发生重大变化？**
  - [ ] 盈利预警
  - [ ] 财务造假
  - [ ] 行业政策变化

---

#### ✅ 调整策略（Rolling）

- [ ] **考虑向下滚动？**（针对CSP被行权风险）
  - [ ] 买回当前Put
  - [ ] 卖出更低行权价、更远到期日的Put
  - [ ] 额外收取权利金

- [ ] **考虑向上滚动？**（针对CC被行权风险）
  - [ ] 买回当前Call
  - [ ] 卖出更高行权价、更远到期日的Call

---

### 📋 复盘检查清单（Post-Trade Review）

#### ✅ 每笔交易复盘

- [ ] **策略执行情况？**
  - [ ] 完全按计划执行
  - [ ] 部分偏离计划：____________
  - [ ] 完全情绪化操作

- [ ] **最终盈亏？**
  - 盈利/亏损：$______ / ______%

- [ ] **预期胜率 vs 实际结果？**
  - 预期胜率：______%
  - 实际结果：[ ] 胜 [ ] 负

- [ ] **改进点？**
  - 做对了什么：____________
  - 做错了什么：____________
  - 下次如何改进：____________

## 专项检查清单

### 🎯 CSP专项清单

- [ ] 我真的愿意以这个价格买入这只股票吗？
- [ ] 账户有足够现金应对行权吗？
- [ ] 行权价是否在合理支撑位？
- [ ] Delta是否在0.2-0.3之间？
- [ ] 设定了止损线吗？

---

### 🎯 Covered Call专项清单

- [ ] 我愿意以这个价格卖出持仓吗？
- [ ] 是否避开了财报前？
- [ ] 股票近期是否有大涨预期？
- [ ] 行权价选在压力位了吗？

---

### 🎯 Credit Spread专项清单

- [ ] 价差比例合理吗？（收入/风险 > 1:3）
- [ ] 两个腿的流动性都足够吗？
- [ ] 最大损失在承受范围内吗？
- [ ] 设定了止损线吗？

## 附录：清单使用建议

### 新手阶段（0-6个月）
- 每笔交易**必须**完整走一遍所有清单
- 打印出来贴在电脑旁
- 复盘时对照清单检查遗漏

### 进阶阶段（6个月-2年）
- 熟练后可以简化为核心清单
- 重点关注风险管理部分
- 建立自己的清单版本

### 专业阶段（2年以上）
- 清单内化为直觉
- 但依然建议保留书面清单
- 用于复盘和教学
